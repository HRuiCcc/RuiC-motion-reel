# 设计语法

这份文档回答一个问题：**为什么同样是用代码画的，有的片子像 demo，有的像作品集。**
下面全部是量出来的做法，不是审美口号。

## 一、时间：先有网格，再有镜头

整片锁在音乐网格上，**每个场景正好一小节**。这样"剪辑点落在强拍上"是**结构决定的**，
不是后期对轴对出来的。用户听到的重音和看到的切换是同一件事。

```
秒数 = 小节数 × 4 × 60 / BPM        BPM = 240 × 小节数 / 秒数
15 秒：8 小节→128 BPM | 6→96 | 5→80 | 4→64
```

**一小节可以拆成 4 拍用**：场景 02 常做成「一拍一个词」，
四个词就是四次独立入场，等于 1 小节里塞了 4 个镜头，观众感觉节奏很快但结构没乱。

镜头的内部也按拍推进（`t` 的单位是秒，用 `T.BEAT` 折算）：
- 第 1 拍：主体入场
- 第 2 拍：规则线/副标入场
- 第 3 拍：注解、读数
- 第 4 拍：稳定，等下一切

## 二、字体：成对出现，尺寸靠解不靠猜

### 搭配
| 用途 | 字体 | 为什么 |
|---|---|---|
| 暗色科技 | Archivo Black + JetBrains Mono | 重型无衬线压场 + 等宽技术标注 |
| 印刷/编辑 | Bodoni Moda + Inter | 高对比迪多尼做标题，无衬线做图注 |
| 通用备选 | Inter 900 / Fraunces | — |

规则：**一个重型标题字 + 一个等宽/技术字**就够。三种以上必散。

### 字号必须解出来
硬写字号是最常见的翻车点——品牌名换一个字就撑出画幅。用 `fonts.fit_size()`：

```python
size = F.fit_size(word, W * 0.82, F.display, track_ratio=-0.026)
```
指定"这一行要占多宽"，字号反解。**字距按比例给**（`-0.026` 而不是 `-4px`），
否则大字号会显得松散、小字号会挤死。

### 字块位置要用字高标定，不是行高
`fonts.cap_band(f, cy)` 给出字高带的上下边；`core.text(anchor="mm")` 按字高带居中。
排版时按"cap center"给坐标，不要按基线——基线会随字体、字号漂。

## 三、构图

### 地平线/环境带
暗场片最容易做出"廉价感"的地方是纯黑底。做法：**一条椭圆形的环境光带** + 一条很淡的
地平线，位置随场景演进缓慢移动（例如从 300 移到 470）。

```python
c.add += gauss(W, H, CX, hz, 600, 112)[..., None] * np.array([0.024, 0.072, 0.104])
p.line([(96, hz), (W-96, hz)], ACCENT, 3.0, 0.20)   # 紧芯
p.line([(96, hz), (W-96, hz)], ACCENT, 1.3, 0.12)   # 软晕
```
幅度是**万分位**量级（0.01~0.1），不是"随便给个蓝色"。见「五、校准」。

### 整场反白
一支片子里放 **一次** 整场反白（暗→亮），放在中段偏后。它提供的是**生理刺激**：
观众的眼睛在暗场里待久了会钝化，一次白场能把注意力重新拉满。
反白场的调色链要单独给（`chrome.POST[5]` 那种 `light=True`）：关 bloom、关扫描线、
颗粒减半、暗角减到 0.15。

### 一个角落只放一样东西
HUD 四角固定：左上品牌、右上片名、左下时间码、右下场景名。中下放 N 点指示器，
最底一条进度条。**不要在这些位置塞内容**。

## 四、动效

### 入场三件套
1. **错帧**：逐字/逐元素延迟 0.04~0.06 秒，整块一起出现最死板
2. **缓动**：`out_expo`（快进慢定）是通用解；落位用 `out_back` 带一点过冲
3. **压印**：落位瞬间把不透明度推过 1（`impact()`），两三帧后回落——"按下去"的感觉

### 切点即重音
每次切点叠一次白光爆闪，衰减 0.055 秒：

```python
flash = k * np.exp(-tl / 0.055)      # tl = 本场已过秒数
c.add += flash * np.array([0.86, 1.0, 0.90])   # 带品牌偏色，不是纯白
```
**必须放在暗角之后**。放在之前的话四角会被压灰，爆闪变成一片灰雾。
3D 场或大面积亮场（k 降到 0.4）不能给满白，否则整帧洗白。

### 缓动表
| 用途 | 函数 |
|---|---|
| 入场（通用） | `anim.out_expo(t/0.6, 4.2)` |
| 落位带过冲 | `anim.out_back(t/0.2, 1.9)` |
| 弹性（重物落下） | `anim.out_elastic(t/0.5, 0.34, 5.6)` |
| 脉冲衰减（爆闪/抖动） | `anim.pulse(t, 7.0)` |
| 分段编排 | `anim.ease_path([(0.0,0),(1.46,1.0),(1.60,0)], tl)` |
| 循环呼吸 | `1.0 + 0.05*np.sin(t*1.9)` |

## 五、亮度必须量，不能看

编码/调色的头号问题是**整体亮了 2~3 倍**还看不出来（显示器会骗你）。
对着参考片同位置量三个数：均值、中位数、p95。

```bash
ffmpeg -v error -ss <t> -i ref.mp4 -frames:v 1 -f rawvideo -pix_fmt rgb24 - | python3 -c "
import sys, numpy as np
a = np.frombuffer(sys.stdin.buffer.read(), np.uint8).reshape(720,1280,3).astype(np.float32)
bg = a[::6,::6].reshape(-1,3)
print('mean', bg.mean(0).round(1), 'median', np.median(bg,0), 'p95', np.percentile(bg,95,0))"
```

判据：
- **中位数**决定底色深浅（暗场片常在 5~30 之间）
- **p95** 决定字幕亮度（白字约 200~250）
- 均值偏离参考 2 倍以上 = 管线有问题，**不要用调色去补**

常见真因见 `gotchas.md` 的「显示空间直出」一条。

### 字体比例核对法
要贴近某条参考片，量它定稿字块的**字高 / 字宽比**再选字体：

```python
F.measure(F.display(size), "MOTION", -4) / cap_height   # 量的
# 参考片：cap 105px / width 676px => 6.44
# Archivo Black 6.63 | Inter 900 5.83   => 用前者
```
比目测"感觉像"可靠得多，一次就能选对。

## 六、颜色也可以被算出来，不必「挑」

往前再走一步：如果你知道光的**物理量**，颜色就是解出来的，不是选出来的。
`engine/color.py` 就是干这个的（普朗克定律 → CIE 1931 配色函数 → XYZ →
线性 sRGB → 色域拟合）：

```python
blackbody(5772)     # 太阳表面温度的黑体是什么颜色 -> (255, 241, 234)
spectral(656.3)     # 656.3 nm 的光 -> Hα 的红
shade(2000, 0.09)   # 同一块 2000 K，只给 9% 的光 -> 暗色底板
```

好处是片子里的每个颜色都能追到一条物理量上：底板是「2000 K 压到 9% 曝光」，
读数色是 486.1 nm（Hβ），日食那一场的绿是 530.3 nm（Fe XIV 日冕绿线——照片里
日冕发绿就是因为这条线）。**一个暗色主题不是"另挑一套暗色"，而是把同一组色读到
曝光的另一端**——这条和下一节的原则是同一件事。

色域拟合要有：2000 K 和 420 nm 都落在 sRGB 之外，直接 clip 会把色相掰弯，
正确做法是朝等能白去饱和（丢的是饱和度，不是色相），和人眼/相机一样。

## 七、色板

- **有品牌就必须实测**（官网样式表 / 产品截图），并在 `theme.py` 里注明来源。
- **亮色品牌的暗色版不是另一套色**：底板用"品牌墨色压暗"，主色仍是品牌本体，
  再把品牌色板里的语义色（信息蓝/警告橙/危险红）拿来做读数——片子立刻属于这个品牌。
- 一个强调色 + 一个次强调色 + 一档中性灰阶，就够了。
