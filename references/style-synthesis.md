# 一句话 → 一套视觉：样式是怎么推出来的

这条产线不再"从 16 张牌里抽一张"，也不参考本仓库里任何一支历史片。
**句子是唯一的规格来源**，样式是句子的函数。

```
一句话  →  SPEC.md  →  theme.py（色板/网格/画幅）  →  scenes.py（一场一场画）
```

`scripts/brief.py` 负责前半段；后半段是人和 Agent 的活。同一句话永远给同一个结果，
换一句话必须明显换一套样子——这是这套东西唯一要守住的性质。

---

## 一、句子被读成六个量

| 量 | 从哪读 | 读不到时 |
|---|---|---|
| 时长 | `20 秒` / `半分钟` / `1 分钟` | 15 秒 |
| 画幅 | `竖屏` `9:16` `方屏` `4K` | 1920×1080 |
| 帧率 | `60fps` `24 帧` | 30 |
| 冷暖 | `暖/咖啡/日落` `冷/夜/科技` `极简/中性` | 中性 |
| 质感 | `胶片` `印刷/riso` `霓虹` `纸艺` `极简/杂志` `3D/金属` | 编辑排版 |
| 节奏 | `慢/舒缓` `快/卡点` | 中 |

再加两条覆盖规则：**句子里点名了颜色**（绿/青/蓝/紫/粉/红/橙/黄/棕）就直接定主色相；
**句子里写了白底/亮底或黑底/暗色**就直接定明暗，不让质感把它带跑。

时长读出来之后不是直接用：要反解出一组 **每小节整数帧** 的 BPM/小节
（`seconds = bars × 240 / BPM`），否则切点会落在半帧上。
`--brief` 会自动做这件事，并在 SPEC.md 里写明用的是什么。

## 三、色板怎么反解（别凭手感配）

一套色板只有一个自由度：**基色相**（由冷暖决定，26° / 214° / 210°）和**主色相**
（由质感或句子里点名的颜色决定）。其余全是同一个 H/S/L 在明度上的切分：

```
INK       基色相, 低饱和, L 0.03   ← 最深的一层
BG0/1/2   基色相, 中饱和, L .05/.09/.14
ACCENT    主色相, 高饱和, L 0.50
ACCENT_BR 同色相, L 0.64            ← 辉光用
ACCENT_LT 同色相, 低饱和, L 0.80    ← 淡底/描边
ACCENT_DK 同色相, L 0.30            ← 深压
ALT       主色相 +150°, L 0.58      ← 只做第二强调
```

亮底的片子把整组明度反过来（纸白 0.94~0.96），但**色相不动**——
不是换一套颜色，是同一套颜色读到曝光的另一端。

规则的好处：想换主色只改 `ACCENT` 一族四个值，其余自动跟得上；
一套片子里所有"深一点/浅一点"都同源，不会出现三四种互不相干的蓝。

## 四、质感决定字体与运动语法

| 质感 | 标题 / 读数 | 缓动 | 入场 | 转场 | 后期 |
|---|---|---|---|---|---|
| analog 胶片 | Bodoni 700 / JB Mono 400 | soft | 淡入上浮 | flash-frame | halation + 两级颗粒 + 片门微抖 |
| print 印刷 | Fraunces 900 / JB Mono 400 | stepped | 油墨滑入 | ink-wipe | 网点 + 套印偏移 + 纸纹 |
| neon 霓虹 | Archivo Black / JB Mono 500 | punch | 砸入缩放 | hard-flash | bloom + 色差 + 扫描线 |
| paper 纸艺 | Fraunces 900 / JB Mono 400 | spring | 落下回弹 | page-turn | 纸纹 + 投影 + 手撕边 |
| editorial 编辑 | Bodoni 700 / Inter 500 | linear | 遮罩揭示 | wipe | 无颗粒，只有纸白与发丝线 |
| dimensional 3D | Archivo Black / JB Mono 500 | soft | 绕入 | depth-push | 点云 + 景深 + 布光 |

**别把六种混着用**：选了 editorial 就别加 bloom，选了 neon 就别上纸纹。
混用是"看起来像模板"的第一原因。

## 五、反模式（这几条是这条产线改名之前的样子）

1. **照抄历史片的配色**：把上一支的 `ACCENT` 拎过来改个色相。那不是新样式，是复刻。
2. **不管句子先写场景**：先画了三个镜头再去想"这是什么调"——顺序反了。
3. **一上来就上 3D + 霓虹 + 网页感**：这是最容易的，也是最像别人片子的。
   句子没说"科技/霓虹"时，默认应该是编辑排版或纸艺这类轻的。
4. **给每个元素都加辉光**：辉光只在"该发光的东西"上（光源、能量、读数），
   不是装饰。整片 70% 的面积应该是安静的。
5. **时长靠"凑"**：先定了 12 个场景再去算秒数。应该先定时长，再让网格决定小节数。

## 六、收工前自检

- `SPEC.md` 里每一行"依据"都能指回句子里某个词——指不回去的，就是你自己加的，
  要能说清为什么加。
- 换个句子再跑一次 `brief.py`，得到的是另一套色板/字体/密度；如果是同一套，说明读句子的规则漏了。
- 片子里所有颜色都能在 `theme.py` 的色板里找到出处，没有"临时调的一个蓝"。
- 六种质感只用了其中一种。
