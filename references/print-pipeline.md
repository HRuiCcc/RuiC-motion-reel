# 印刷管线：分色、网点、叠印

一套让代码渲染读起来像**丝网印/riso**的做法。核心观念：
**颜色不是"给像素指定颜色"，而是把几块油墨版叠印算出来的**——
粉压蓝是真紫、黄压蓝是真绿。颜色来自乘法，不是赋值。

## 一、纸

```python
plate = paper_field(W, H, base=(243,238,229), seed=11,
                    tooth=0.020, mottle=0.016, fibre=0.012,
                    warm=(1.0, 0.985, 0.955))
c.rgb[:] = plate
```
三个层次缺一不可：
- **mottle** 低频斑块（纸浆不匀）
- **tooth** 每像素细粒（纸面粗糙）
- **fibre** 各向异性拉长的噪声（`fiber_field`：同一噪声横向/纵向各自狠模糊再合并）

少了 fibre 就只是"加了噪点的纯色"，像屏幕不像纸。

## 二、叠印：multiply

```python
c.composite(lrgb, la, mode="multiply")   # rgb = rgb * (1 - la*(1 - lrgb))
```
`Canvas.stamp(mask, color, mode="multiply")` 可以直接把 numpy 遮罩当一块版压上去。

## 三、油墨覆盖率（最容易被忽略的一笔）

平涂的色块是最大的"数码味"来源。真实印刷的网点/实地**永远不是 100% 均匀**：

```python
c.coverage = ink_coverage(W, H, amount=0.20, scale=13)   # 低频起伏
c.soften = 1.0                                            # 网点边缘吸墨
```
`Canvas` 上设一次，之后每次 `commit`/`stamp` 都会自动带上。

## 四、分色：明暗切块 + 三角隶属度

把一张连续调的明暗图拆成几块版。每块版取明暗轴上的一段**三角隶属度**，
相邻版**刻意重叠**一点，重叠处叠印生成中间调：

```python
TONES = [   # (中心, 半宽, 网线角度, 油墨)
    (0.82, 0.30, 75.0, "YELLOW"),
    (0.58, 0.32, 15.0, "PINK"),
    (0.33, 0.32, 45.0, "BLUE"),
    (0.09, 0.26, 75.0, "INK"),
]
for centre, width, angle, ink in TONES:
    mem = clip01(1.0 - np.abs(lum - centre) / width)
    scr = halftone(mem, cell=6.0, angle=angle, soft=0.50) * cov
    rgb = plate(rgb, scr, INK_COLOR[ink], alpha=0.95)
```

**网线角度必须错开**（15° / 45° / 75°）。相同角度会叠成规则花纹（摩尔纹），
角度分开才出印刷的玫瑰斑。

## 五、网点

```python
halftone(field, cell=6.0, angle=15.0, soft=0.5)
```
在**旋转过的点阵**上算到最近网点的距离，再用 field 控制点面积（`sqrt(field)` 保面积线性）。
`cell` 就是网线密度：1280px 宽 ≈ 133 lpi 对应 `cell≈6`；
交付 1920px 宽要保持同样的网线，`cell≈9`。
**网点是细节，靠它吃饭的片子要按交付尺寸排版**（`W, H = OUT_W, OUT_H`，见 SKILL.md 的「交付规格」），否则 1080p 的网点来自 720p 重采样，会糊。

`soft` 是抗锯齿宽度，0.4 太硬（点发方），0.6 太糊（丢网点感），**0.48~0.52 最像**。

## 六、套印偏移（misregistration）

riso 的灵魂。每块版平移几像素，颜色边缘就会"错开"，混出第四色：

```python
scr = shift2(scr, (7.0, -5.0))      # 这块版歪了
# 编排：偏移量平时为 0，某几拍拉到 (86,-52) 等大值，再"啪"地归位
```
归位瞬间再叠一个 5~7px 的反向抖动并指数衰减，就是"套准"的力度感。

## 七、主版线（key line）

`outline(cov, w=1)` —— 覆盖率减去腐蚀后的覆盖率，得到**内侧剪影线**。
一条细主版线能让形体从"照片"变成"版画"。
`text_outline()` 同理，用 `MinFilter` 腐蚀后相减，**注意要在裁切后的字形包围盒上做**，
不然 2560×1440 全画幅跑 MinFilter 会慢到不可用。

## 八、版面家具

| 元素 | 要点 |
|---|---|
| 裁切线 | 必须在**活件区之外**（`T.M` 以外），这才是真裁切线的位置 |
| 套准规 | 圆环 + 十字 + 两个彩色象限点，最能一眼认出"这是印刷" |
| 折痕 | 中线两侧一压一提的极淡明暗（`fold()`，幅度 0.006 量级） |
| 压印颗粒 | `press_grain()`，0.013 左右，比屏幕颗粒更细 |
| 图注引线 | `leader()`：先斜线再肘弯，端点一个小圆点 |

## 九、印刷场专属的坑

- **亮场上的暗字会被 bloom 冲灰**。白底黑字时 bloom 会把亮底糊到字上。
  做法：该拍 `post_override = dict(bloom=(0.97, 0.20), chroma=0.7, ...)` 基本关掉 bloom。
- **"亮场"要做成乘法，不是加色**。用 `c.rgb *= (0.84 + 0.28*gauss(...))` 压亮，
  不要 `c.add += 0.42`——加色会把同等的亮度加到字上，黑字直接变灰字。
- 不要给印刷场加暗角、扫描线、色差。纸没有这些。
