# 配乐合成

`engine/dsp.py` + 项目里的 `audio.py`。**不采样、不下载、不用外部素材**，全部合成。

## 一、先钉时间网格
BPM 由"总秒数 ÷ 小节数"反推（见 `design-grammar.md`），
然后所有事件都用"第几小节第几拍"定位，不要写绝对秒数：

```python
def at(bar, beat=0.0):
    return int(round((bar * T.BAR + beat * T.BEAT) * sr))
place(L, kick, at(2, 1.5), 0.86)     # 第 2 小节第 1.5 拍
```

## 二、滤波：FFT 重叠相加，响应随时间变

```python
filt(x, sr, fn=None, block=4096)      # fn(freqs, t_centre) -> gain
```
每个块单独取响应，所以**一次调用就能做滤波器扫频**（riser 的核心）：

```python
def resp(f, t, a=300, b=6500, d=1.8):
    c = a * (b/a) ** min(1.0, t/d) ** 1.8      # 中心频率随时间上扫
    return (f/c)**1.6 / (1+(f/c)**1.6) * 1/(1+(f/min(c*5,16000))**2)
```
预置响应：`lp(cut, slope)` / `hp(cut, slope)` / `bp(lo, hi, slope)`。

**归一化必须除以窗和，不是窗平方和**（窗只加了一次）。见 `gotchas.md`。

## 三、常用音色

| 函数 | 音色 | 要点 |
|---|---|---|
| `kick` | 底鼓 | 正弦 + 指数下滑（120→45Hz）+ 4ms 噪声点击 |
| `snare` | 军鼓/刷子 | 两个音 + 带通噪声；`brush` 参数拉长噪声尾=刷子感 |
| `hat` | 踩镲 | 高通噪声，闭镲 0.018 秒衰减 |
| `clap` | 拍手 | 4 个 8~12ms 间隔的噪声爆发 + 0.16 秒尾巴 |
| `sub` / `saw_bass` | 低音 | 正弦；锯齿+扫频低通更"有机" |
| `pluck` | FM 拨弦 | 调制比 3.01、指数衰减的调制指数，铃声感 |
| `bell` | 钟/电钢 | 失谐泛音 2.76 / 5.40 + 长衰减 |
| `pad_chord` | 铺底 | 4 层失谐锯齿 + 慢起 |
| `riser` / `impact` / `whoosh` | 转场 | 分别是上扫噪声、爆点、下扫噪声 |

**FM 电钢**：载波 + 指数衰减的调制指数 + 5Hz 慢颤音（tremolo）＝ Rhodes 味。

## 四、磁带味（让"干净"变"有温度"）
```python
L = tape_wow(L, sr, depth=0.0018, rate=0.63)   # 慢速音高漂移
L = reverb_tail(L, sr, taps=((0.097,0.20),(0.163,0.13),(0.251,0.08)))
```
`tape_wow` 用一条缓慢游走的读指针重采样——比加噪声有效得多。
`vinyl_bed()` 给底噪：稀疏爆点 + 高通嘶声，别超过 0.5% 电平。

## 五、编排
按小节写"编曲表"，一小节一行，标注该小节**哪些乐器在场**：

```python
style = ["intro", "drop", "drop", "break", "full", "full", "rise", "out"][bar]
```
- 前 1~2 小节留白（只有铺底 + 稀疏底鼓），给后面的进入留空间
- 中段某小节**抽掉底鼓两拍**（break），再回来——这是最便宜的高潮铺垫
- 最后 1~2 小节做减法，留一个干净的尾音

**转场要压在切点上**：`riser` 放在小节末 0.96 小节处，`impact` 放在下一小节第 0 拍。

## 六、混音与电平
1. 各轨滤波（`lp(13500)` + `hp(30)` 去掉无用的两端）
2. 混响抽头（左右用不同延迟，自然加宽）
3. `tanh` 软限幅
4. **先做首尾淡入淡出，再归一化**
   （顺序反了的话，开头一个瞬态会把整首的天花板顶掉，整片偏轻）
5. 留余量：目标采样峰值 **0.82~0.86**，
   因为 **AAC 编码后采样间峰值会超过采样峰值**（实测会超 0.5~1 dB）

目标响度：暗色科技片约 −9.4 LUFS，温暖/慢片约 −13 LUFS，真峰 < −0.5 dBTP。
